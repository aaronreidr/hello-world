Connect to the printer network · Blank panel? Read connection help

These pages load directly from your network. Connect to the office network or VPN, and allow local-network access if your browser asks. GitHub Pages uses HTTPS, so browsers without a local-network exception may block these HTTP pages. Try current Chrome. If a printer refuses embedding, use its Open link; this dashboard cannot override the printer’s security settings. An internal web server or an IT-managed proxy may be needed. Browser connection details.

Fit scales the page to show its device overview. Choose a larger zoom and scroll inside a panel for readable details. Refresh returns a panel to the Device page. Auto-refresh is off initially so it will not interrupt your work.

Embedded pages show the printers’ own information. Connection and device status cannot be verified by this dashboard.
